# Security policy

## Reporting a vulnerability in erlc.rs

Report it privately through
[GitHub's private vulnerability reporting](https://github.com/ERLC-Rust/erlc.rs/security/advisories/new).
Do not open a public issue.

Include the affected version, a description and steps to reproduce. Never include a real
server key or global API key.

## Vulnerabilities in the ER:LC API itself

Report those to the ER:LC API team as described in their
[acceptable use policy](https://apidocs.erlc.gg/policies/aup), not here.

## Leaked keys

If a server key is exposed, regenerate it in your private server settings immediately.
